# СЕВЕР — сайт услуг по Яндекс Бизнесу и Картам

Статический адаптивный сайт: HTML, CSS, JavaScript. Без сборки и платных библиотек.

## Перед публикацией
- Проверьте контактные данные и ссылки.
- Отредактируйте стартовые цены в `index.html`.
- Убедитесь, что формулировки услуг соответствуют вашим реальным навыкам.
- Кейсы и отзывы не добавлены, чтобы не создавать вымышленные результаты.
- Название «СЕВЕР» — рабочее; перед коммерческим использованием проверьте доступность названия и домена.

## Бесплатная публикация на GitHub Pages
1. Создайте аккаунт на https://github.com/ (если у вас его нет).
2. Нажмите **New repository**.
3. Назовите репозиторий `anvi-yandex-studio`. Для простоты выберите **Public** и создайте репозиторий.
4. Нажмите **Add file → Upload files**.
5. Загрузите файлы `index.html`, `styles.css`, `script.js`, а также папку `assets` из этой директории. Не загружайте ZIP как единственный файл — GitHub Pages должен видеть `index.html` в корне репозитория.
6. Нажмите **Commit changes**.
7. Откройте **Settings → Pages**.
8. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку `main` и папку `/(root)`. Нажмите **Save**.
9. Через несколько минут адрес появится в разделе Pages. Обычно он будет похож на `https://ВАШ-ЛОГИН.github.io/anvi-yandex-studio/`.
10. Откройте ссылку с телефона и проверьте все кнопки.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Бесплатная альтернатива: Netlify
1. Откройте https://app.netlify.com/drop
2. Перетащите папку сайта (или папку после распаковки архива) в область загрузки, если сервис предлагает такой способ.
3. Дождитесь публикации и сохраните выданный адрес.
4. Учитывайте текущие условия и ограничения бесплатного тарифа Netlify.
